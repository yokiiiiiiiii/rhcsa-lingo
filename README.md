# RHCSA.LINGO 💻

Интерактивный тренажер для подготовки к сертификационному экзамену **Red Hat Certified System Administrator (RHCSA)**, актуализированный под **RHEL 10**.

![RHCSA Lingo](https://img.shields.io/badge/Status-Active-success.svg) ![React](https://img.shields.io/badge/React-18-blue.svg) ![TypeScript](https://img.shields.io/badge/TypeScript-Ready-blue.svg) ![Tailwind](https://img.shields.io/badge/Tailwind_CSS-3.4-38B2AC.svg)

## 📌 О проекте

RHCSA Lingo — это геймифицированное веб-приложение в стиле хакерского терминала. Оно помогает системным администраторам и DevOps-инженерам довести до автоматизма написание команд Linux, запомнить правильный синтаксис флагов и уверенно чувствовать себя в консоли.

Приложение спроектировано так, чтобы с ним было удобно работать как с десктопа, так и с мобильных устройств по пути на работу.

## ✨ Ключевые особенности

- 🚀 **150 практических задач**: База тщательно отобранных вопросов охватывает все темы курсов **RH124 (SysAdmin I)** и **RH134 (SysAdmin II)**.
- ⌨️ **Два режима взаимодействия**:
  - **Терминал (TERM)**: Классический ввод с клавиатуры. Поддерживает автодополнение клавишей `Tab` (имитация реального поведения bash/zsh).
  - **Сборка (CHIPS)**: Мобильно-ориентированный режим, позволяющий собирать команды из токенов, словно пазл.
- 🧠 **Интервальное повторение**: Система запоминает задачи, в которых вы ошиблись, и автоматически подмешивает их в начале режима «Mix: Экзамен» для закрепления.
- 📊 **Модуль аналитики**: Детализированная статистика в виде графиков (Recharts). Отслеживайте свой процент успеха (Success Rate) по категориям: *Storage*, *Network*, *Users & Permissions*, *Security (SELinux)* и другим.
- 🛡️ **Умная валидация**: Парсер очищает ввод от лишних пробелов и лояльно относится к краевым кавычкам в командах.
- 📱 **Mobile-First & 100dvh**: Интерфейс построен на жестком Flexbox-каркасе, который не ломается при появлении мобильных панелей навигации браузера. 

## 🛠️ Технологический стек

- **Core**: React 18, TypeScript, Vite
- **Стилизация**: Tailwind CSS v4, кастомные CSS-переменные
- **Графики**: Recharts
- **Иконки**: Lucide React
- **Хранение данных**: LocalStorage API (хранение прогресса, стрик-дней и статистики)

## 🚀 Установка и запуск (Local Development)

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/yourusername/rhcsa-lingo.git
   cd rhcsa-lingo
   ```

2. **Установите зависимости**:
   ```bash
   npm install
   ```

3. **Запустите сервер для разработки**:
   ```bash
   npm run dev
   ```
   *Приложение будет доступно по адресу `http://localhost:3000` (или другому порту, указанному в консоли).*

4. **Сборка для продакшена**:
   ```bash
   npm run build
   ```
   *Скомпилированные файлы появятся в директории `dist/`.*
